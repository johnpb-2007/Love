# Interaction Contract

Rules from the brief, now binding for every section built in Phase 4/5:

- Every section ships **1 hover + 1 click + 1 hidden + 1 ambient + 1 reward** interaction.
- A new discovery surfaces roughly every **15-20s** — ambient spawns (butterflies, balloons, envelopes) are timer/random-driven, not just scroll-triggered, so this holds even if the visitor pauses.
- No two consecutive sections lean on scrolling alone — satisfied structurally by the rule above, but the *dominant* interaction mode also alternates section-to-section (see table) so it doesn't feel repetitive.

## Per-section assignment

| Section  | Hover | Click | Hidden | Ambient | Reward |
|----------|-------|-------|--------|---------|--------|
| Hero | CTA glow-lift | "Begin" → ripple transition | tiny star, click for early achievement | twinkling stars + drifting petals | ripple/confetti on Begin |
| Gallery | photo tilt/glow/reflection | fullscreen modal + particles | rare butterfly lands on one photo | butterflies drifting across | compliment popup, "Butterfly Friend" |
| Reasons | card lift/glow | flip card / No-Button game | hidden hearts (heart-collector) | floating hearts drift up | counter++, unlocks Bonus Letter at 10 |
| Letter | wax seal glows | drag letter out, book opens | ink doodle plays a sound | paper dust motes | "Read the Letter" achievement |
| Timeline | page corner lifts | click/drag to flip page | secret note tucked in one page | paper-dust drift | "Storybook Complete" |
| Gift | box wiggles harder | 3-click sequence → confetti | cat peeking behind the box | sparkle dust around box | confetti + wish jar message |
| Ending | "Hug Me" glow pulse | zoom + heartbeat + fade | full collectible set → sunrise ending | fireworks / birds | final message reveal |

Each section's signature interaction (bold verb above) is intentionally different in *kind* — tilt vs. drag vs. multi-click vs. hidden-object — so consecutive sections don't repeat the same motion language even though the checklist is identical.

This table is the spec Phase 4 (components) and Phase 5 (sections) build against — no new interaction ideas get added ad hoc mid-build; if something's missing, it gets added here first.
